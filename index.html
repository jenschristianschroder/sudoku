How to play

Fill each empty cell with a number from 1 to 9. Every row, column, and 3×3 box must contain each number once. Notes help you track possibilities, and Hint reveals one correct cell. Completing games unlocks harder levels unless you turn off progression requirements in Gameplay settings.

Storage, privacy & security

Your current game, history, stats, gameplay settings, and theme stay in this browser on this device. There is no account, cloud sync, or remote game database. Browser storage is not encrypted. You can delete all device data from this menu at any time. Share links contain the puzzle and filled cells, but never your statistics.
